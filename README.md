# 🎵 Aero Music Player (BETA)

> **Nota:** Este es un proyecto de prueba en fase BETA. Está en desarrollo activo y aún carece de varias funciones que se irán añadiendo poco a poco.

Un reproductor de música de escritorio creado desde cero en **Rust**, con una interfaz gráfica inspirada en la estética *Frutiger Aero* (Windows Vista/7).

## **Características actuales**
*   Reproducción de archivos MP3, WAV y FLAC.
*   Lista de reproducción (Playlist) automática.
*   Controles básicos: Play, Pausa, Stop, Anterior y Siguiente.
*   Modos de reproducción: Aleatorio y Repetir (1 o toda la lista).
*   Control de velocidad y volumen.
*   Efecto visual de ecualizador simulado.

## **Tecnologías usadas**
*   **Rust** - Lenguaje principal.
*   **egui / eframe** - Interfaz gráfica.
*   **rodio** - Motor de audio.

## **Cómo probarlo?**
1. Descarga el archivo ZIP desde la sección **Releases**.
2. Descomprime el archivo.
3. Coloca tus archivos de audio `.mp3` dentro de la carpeta `musica`.
4. Ejecuta `Aero Music Player.exe`.
